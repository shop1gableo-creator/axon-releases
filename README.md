# Axon — téléchargements

Ce dépôt contient **uniquement les installateurs** d'Axon (Windows 10 et 11).

1. Ouvre **Releases** (colonne de droite) → la dernière version.
2. Télécharge `Axon-Setup-x.y.z.exe` et lance-le.
3. Ensuite, Axon se met à jour tout seul : un bandeau propose « Redémarrer pour mettre à jour ».

Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même* (l'installateur n'est pas encore signé).
